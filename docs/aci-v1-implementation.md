## Existing-first integration

`pricing.py` retains `PreflightCostEstimator` as the only production estimator.
`pricing_profile.py` supplies strict bounded rule compilation, unit normalization
and quantity/charge arithmetic. One data resource,
`data/video-tariff-rules.json`, scopes documented rules to exact model revisions;
rates come from the existing catalogue snapshot. No model-name matching calculator,
runtime price constants, eval, calibration, database or dependency was added.

The cost adapter reads effective validated active inputs. Missing quantities are
distinct from missing external semantics; source duration is not automatically
output duration. Decimal arithmetic resolves exclusive bases, additions, allowances
and minima. Known incomplete components do not become a total. Finite ranges need
complete correlated alternatives. Safe single documented output-second templates
preserve ordinary legacy callers; unknown/complex fees still fail closed.

The existing estimate branch and local route expose the additive v2 cost contract.
Legacy AVAILABLE/estimated_cost_usd is numeric only for FORMULA. RANGE, RATE_ONLY,
PARTIAL, STALE, UNKNOWN and INVALID remain distinct. Omitted v2 audio is not false.
No new submit, upload, routing, authentication or provider execution path exists.

The existing header badge supplies native state labels and accessible details,
including collapsed presentation, quantities/rates, assumptions and reasons.
Revision correlation rejects old replies. Existing catalogue refresh invalidates
cost even when only rates change; failed/disconnected refresh clears current
numeric cache without inventing a separate freshness policy.

Already materialized native image/video/audio display metadata may provide bounded
scalar HINT values and trigger refinement. Estimation never executes an upstream
node, encodes, fetches media URLs or stages/uploads media. Missing or unproved
metadata remains missing; client hints do not become actual billing authority.

## Pricing-neutral controls

The same resource declares exact revision/method/provider/key neutrality for the
reviewed Kling `cfg_scale` and `negative_prompt` controls. This intersects current
Core types and live allowlists; unknown, complex/count/media/output controls are
not silently ignored. Cost descriptors contain decimal-string numbers or Unicode
text length, never selected prompt content. Existing Core validation checks safe
typed descriptors using synthetic nonsecret text solely for length validation.
This is advisory cost validation, never authorization to Generate.
